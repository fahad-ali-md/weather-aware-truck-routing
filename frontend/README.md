# Wayfinder frontend

The React, TypeScript, Vite, and MapLibre frontend lives in this directory.

```bash
pnpm install --frozen-lockfile
pnpm dev --host 127.0.0.1
```

Start the Django API on `127.0.0.1:8000` first. For full setup, risk rules, commands, screenshots, and deployment information, see the [project README](../README.md).
